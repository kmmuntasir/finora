# Interface translation

Finora's interface text goes through `web/src/i18n`. English is the source
language and doubles as the key; other languages live in
`web/src/i18n/<language>/*.json`, one file per feature area, merged at load.
The Bengali catalogue is a **draft awaiting review by a native speaker**
(decision 0009).

## Writing code

- `import { msg, t, tn } from "@/i18n";`
- `t("English text")` for every user-visible string: JSX text, `aria-label`,
  `title`, `placeholder`, non-empty `alt`, `label` props, toast messages,
  error messages shown to people, and option labels.
- Placeholders: `t("Signed {name} out of {count} devices", { name, count })`.
  Never build a sentence by concatenating translated pieces; translate the
  whole sentence with placeholders, because word order differs between
  languages.
- Counts: `tn(count, "{count} movie", "{count} movies")`. Both English forms
  are keys; `{count}` is filled in automatically.
- Never call `t()` at module scope (constants, option arrays). Modules load
  before the language does, so the text would stay English. Mark the
  English with `msg("…")` in the constant and call `t(option.label)` when
  rendering.
- A sentence containing a link or other element: translate the parts on
  each side of it separately, keeping each part a meaningful phrase.
- Don't translate: anything that comes from Jellyfin or a provider (titles,
  names, overviews, release names, server error text), codec and format
  names (HEVC, SRT, 4K), keyboard key names, URLs, product names (Finora,
  Jellyfin, OpenSubtitles, Google), `console` and log messages, CSS classes,
  test IDs.
- `pnpm i18n:check` lists strings missing from the Bengali catalogue (and
  entries nothing uses). It runs in `pnpm check`. Only literal strings are
  found, so always pass a literal to `t`, `tn` and `msg`.

## Bengali style

Natural Bangladeshi Bengali as people use it in apps: short, polite (আপনি),
no stiff Sanskritised words where an everyday word or a common English
loanword is what people say. Keep `{placeholders}` exactly. Keep
punctuation light; use the Bengali full stop (।) for full sentences and
none for labels and buttons.

## Changing language

Settings → Appearance → Language, and a switcher on the sign-in page. The
choice is a server-synced Finora preference, mirrored on the device so the
sign-in page uses it. Changing it remounts the routes; music stops.
